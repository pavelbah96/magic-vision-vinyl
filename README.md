# Magic Vision · Пластинки — веб-версия для телефона

Та же функция, что в приложении для очков, но без очков и без установки: телефон, его камера и браузер.
Снимок обложки → альбом → конкретное издание → цена на Discogs.

## Запуск

```bash
./scripts/serve-web.sh
```

Скрипт печатает адрес; откройте его в Safari на телефоне в той же сети Wi‑Fi. В настройках (шестерёнка)
введите ключ OpenAI. Токен Discogs необязателен.

Страница статическая и работает с любого HTTPS-хостинга как есть: достаточно выложить содержимое папки `web/`.
На HTTPS её можно добавить на экран «Домой», и она запускается как отдельное приложение.

## Устройство

| Файл | Что в нём |
|---|---|
| `core.js` | Логика без сети и экрана: признаки издания, страны, оценка и вердикт, запрос к модели. Перенос `MagicVision/Core`. |
| `api.js` | Запросы к OpenAI и Discogs прямо из браузера, ограничитель частоты Discogs. |
| `app.js` | Экран и ход работы: снимки, поиск, результат, крупный план, история, настройки. |
| `sw.js`, `manifest.webmanifest` | Запуск с экрана «Домой» (только на HTTPS). |
| `tests/core.test.mjs` | Автономные проверки ядра: `node --test web/tests/core.test.mjs`. |

Баллы оценки изданий и подсказки модели должны совпадать с `MagicVision/Core/EditionMatching.swift`
и `VinylVisionAPI.swift`: меняя одно, меняйте и другое.

## Что хранится и куда уходит

- Ключ OpenAI и токен Discogs — только в `localStorage` этого браузера; каждый уходит только в свой сервис.
- Снимки отправляются в OpenAI для чтения и нигде не сохраняются.
- История хранит название, издание, цену и ссылку на Discogs, без фотографий.
